uLinga for Enterprise Extender (EE)
Modernize SNA Connectivity

← Back to Gateway Products

Modernize Mainframe Connectivity Without Changing Your Applications

For organizations running mission-critical HPE Nonstop and IBM Mainframe environments, maintaining legacy SNA infrastructure is increasingly expensive and difficult to support.

uLinga for Enterprise Extender (EE) provides a standards-based (HPR/IP) solution that transports SNA traffic over modern IP networks—allowing organizations to retire legacy networking technologies while keeping existing applications fully operational.

No application changes. No network redesign. Just seamless connectivity.

Why uLinga/EE?

Legacy SNA environments often require specialized networking equipment, multiple communication protocols, and complex administration.

uLinga/EE simplifies your infrastructure by enabling SNA communication across standard IP networks while preserving existing application interfaces.

Benefits

Modernize legacy SNA connectivity
Eliminate dependence on specialized SNA networking hardware
Reduce infrastructure and operational costs
Consolidate communications onto a single IP network
Improve network monitoring and security
Preserve existing Nonstop and Mainframe applications
Accelerate SNA retirement initiatives

Built for HPE Nonstop Environments

uLinga/EE is purpose-built for mission-critical Nonstop systems and integrates seamlessly with IBM z/OS Communications Server.

Applications continue running exactly as they do today while communications move transparently across an IP infrastructure.

No Application Changes Required

Applications using standard Nonstop APIs continue operating without modification, including:

SNAX/HLS SNAX/CRT SNAX/APC SNALU Standard File System I/O TCP/IP interfaces

This significantly reduces project risk and implementation time.

Key Features - Exceeding All Expectations

Online Configuration

Web browser interface utilising HTML 5 and Web Sockets, with no client software to install.

Tracing

Enterprise Extender protocols designed from the ground up for high performance.

Connections

Advanced Peer to Peer Networking (APPN) End Node to reduce the number of definitions required on your mainframe. Support for all LU types, including APPC (LU6.2) protocols.

Online Management

Interactive command line interface, with support for obey/script files.

APPC Support

Session Services Extensions (SSE) to enable support for SNA secondary applications and devices to “logon” over EE links.

Standard APIs

Support for standard APIs — no application changes required.

Additional Features

✓ Standards-based Enterprise Extender (HPR/IP)
✓ Supports all SNA Logical Unit (LU) types
✓ Seamless Nonstop-to-Mainframe communication
✓ Uses existing IP infrastructure
✓ No specialized routers required
✓ Native compatibility with IBM z/OS Communications Server
✓ Standalone replacement for legacy SNA connectivity technologies
✓ High-performance, enterprise-grade reliability

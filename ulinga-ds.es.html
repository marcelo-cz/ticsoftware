uLinga for Kafka

Streaming de Kafka ligero y de alto rendimiento para datos y aplicaciones de HPE Nonstop.

Un enfoque diferente

uLinga for Kafka se ejecuta como un par de procesos Guardian compilado de forma nativa y habla los protocolos de Kafka directamente sobre TCP/IP, sin librerías Java ni base de datos intermedia. Se comunica directamente con el clúster de Kafka para obtener el mejor rendimiento posible, evitando la plataforma adicional, el punto único de fallo y la latencia que introducen otras soluciones de Kafka para Nonstop.

Pathsend y Guardian IPC

Las aplicaciones envían y reciben datos directamente por IPC o Pathsend con cambios mínimos de código: la menor latencia posible.

HTTP / REST

Enrute solicitudes web a Kafka mediante la interfaz HTTP integrada de uLinga, sin middleware adicional.

uLinga for Enterprise Extender

SNA entre hosts y servidores, de forma nativa sobre IP, conservando sus APIs SNA.

Retire SNA, conserve sus aplicaciones

La infraestructura SNA propietaria restringe la flexibilidad y añade costo y complejidad. uLinga for EE permite a los usuarios de HPE Nonstop y de mainframes IBM migrar de SNA a TCP/IP de forma rápida y fiable, eliminando SNA de partes críticas de la red —incluso de las «colas» de último tramo— sin cambios en el código de las aplicaciones. Las aplicaciones siguen funcionando como aplicaciones SNA mientras usted obtiene visibilidad IP de extremo a extremo.

Enterprise Extender (HPR/IP) UDP/IP Enlaces tolerantes a fallos Sin cambios en la aplicación

Qué ofrece uLinga for EE

Nodo EE / APPN

Participe en el mundo SNA APPN como nodo EE, conservando el acceso a CICS, IMS y TSO, reduciendo las definiciones VTAM, con tolerancia a fallos UDP/IP en enlaces redundantes.

Interfaces nativas de Nonstop

Compatible con HLS, SNAX/APC, SNALU, CRT, Raw Socket e IPC, para que las aplicaciones SNA de Nonstop existentes sigan funcionando sin cambios.

Configuración y trazado en línea

La misma configuración en línea de toda la suite uLinga, más el trazado con Wireshark estándar del sector, con compresión para reducir el almacenamiento.

Gestión WebCon

Gestione y controle el proceso desde cualquier navegador web mediante una interfaz gráfica intuitiva, protegida con TLS 1.2 integrado.

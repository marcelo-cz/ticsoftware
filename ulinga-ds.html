uLinga for Kafka

Lightweight, high-performance Kafka streaming for HPE Nonstop data and applications.

A different approach

uLinga for Kafka runs as a natively compiled Guardian process pair and speaks the Kafka protocols directly over TCP/IP — with no Java libraries and no intermediate database. It communicates straight with the Kafka cluster for the best possible performance, avoiding the extra platform, single point of failure and latency that other Nonstop Kafka solutions introduce.

HPE Nonstop Integration Gateway

uLinga for Enterprise Extender

SNA between hosts and servers, natively over IP — while still retaining your SNA APIs.

Retire SNA, keep your applications

Proprietary SNA infrastructure restricts flexibility and adds cost and complexity. uLinga for EE lets HPE Nonstop and IBM mainframe users migrate from SNA to TCP/IP quickly and reliably — eliminating SNA from critical parts of the network, even the last-wire "tails" — with no changes to application code. Applications keep running as SNA applications while you gain end-to-end IP visibility.

Enterprise Extender (HPR/IP) UDP/IP Fault-tolerant links No application changes

What uLinga for EE delivers

EE / APPN node

Participate in the SNA APPN world as an EE node — retaining access to CICS, IMS and TSO, reducing VTAM definitions, with UDP/IP fault tolerance across redundant links.

Native Nonstop interfaces

Support for HLS, SNAX/APC, SNALU, CRT, Raw Socket and IPC — so existing Nonstop SNA applications keep working unchanged.

Online configuration & tracing

The same online configuration used across the uLinga suite, plus industry-standard Wireshark tracing with compression to reduce storage.

WebCon management

Manage and control the process from any web browser through an intuitive graphical interface, secured with built-in TLS 1.2.

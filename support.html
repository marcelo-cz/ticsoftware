TIC NavigatorBetaEspañol
Version 2.2.3 · Windows 10/11 (64-bit)

Getting ready to install Navigator? Start with the prerequisite check. It takes a few seconds, changes nothing on your PC, and saves a short report. Email the report to support@ticsoftware.com and we will send the license file for your PC.

  1. Run the prerequisite check and email us the report
  2. Receive your license file from TIC
  3. Download the installer (4 parts) and install
Prerequisite check · 5.8 MB Beta guide (PDF)
Installer · NavigatorSetup 2.2.3 (ES)4 parts · 110 MB total
Part 1 · 28.0 MBPart 2 · 28.0 MBPart 3 · 28.0 MBPart 4 · 25.6 MB

How to install: download all four parts, extract each one into the same folder (right-click → Extract All), put your license file in that folder too, then double-click NavigatorSetup-2.2.3-ES.exe. The installer reads the other parts automatically.

Optional: check the download. In PowerShell run Get-FileHash NavigatorSetup-2.2.3-ES.exe -Algorithm SHA256 and compare the result with 358ce3d2ae26da89a802909a281faab8cedca9920d52639839b1215dde9f409d
